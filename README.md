## 🌟 About the Project

Welcome to my personal portfolio!

This website showcases my introduction, educational journey, technical skills, projects, and interests in computer science.

Designed with a modern **black, white, and orangered** colour theme, this portfolio reflects my creativity, curiosity, and passion for learning new technologies.

> 💡 "Turning ideas into code and dreams into reality — one project at a time."

## ✨ Features

- 🏠 **Home Section** — Introduction and welcome message.
- 👩‍💻 **About Me** — Background, interests, and academic journey.
- 🛠️ **Skills Section** — Visual representation of technical skills.
- 🎓 **Education Timeline** — Academic milestones and qualifications.
- 💻 **Projects Section** — Showcase of technical and practical projects.
- 📩 **Contact Section** — Contact form layout and communication links.
- 🌐 **Social Links** — Quick access to selected social platforms.
- 🎨 **Modern UI** — Clean layout with a black and orangered theme.
- ✨ **Hover Effects** — Interactive buttons, cards, and visual transitions.
- 📱 **Responsive Foundations** — Mobile-friendly styling for selected sections.
